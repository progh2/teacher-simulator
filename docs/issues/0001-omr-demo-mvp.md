# OMR 카드 검사 데모 MVP

- **상태:** 완료
- **라벨:** `demo`, `omr`, `mvp`
- **작성:** 2026-11-04

## 목표

웹에서 바로 돌아가는 OMR 카드 검사 미니게임 데모를 만든다.
명렬표 순서 정렬 + 뒤집기 + 오류 판정 + 채점/해설까지 한 사이클.
