# 교사 시뮬레이터 (Teacher Simulator)

예비교사·교육실습생·학생이 **교사의 자잘한 잡무**를 미니게임으로 연습하는 웹 프로젝트입니다.
실제와 비슷한 서류·카드를 책상 위에서 만지며 실수를 줄이는 것이 목표입니다.

> 데모 첫 미니게임: **OMR 카드 검사** (허브의 다른 타일은 잠금)

## 실행

```bash
npm install
npx playwright install chromium   # e2e/스크린샷용 (최초 1회)
npm run dev          # http://localhost:5173
npm run build        # dist/ (GitHub Pages용, base './')
npm run preview      # 빌드 결과 미리보기
npm run e2e          # easy+normal 만점 플로우 · 콘솔 에러 검사 · docs/screenshots/ 갱신 · 클릭/드래그 회귀
npm run test:score   # 시드 고정 채점 스모크 (easy/normal/hard)
npm run test:viewport # 1280×800 · 1024×768 정렬 오버플로 검사 (cardsOut/slotsOut)
npm run screenshots  # 레거시 단계 샷 스크립트
```

시드·난이도: `?diff=easy&seed=20261104` (쉬움/보통/어려움 = easy/normal/hard).

정렬 단축키: `F` 뒤집기 · `R` 위아래 · `Enter` 트레이로.

## OMR 카드 검사

1. **응시 인원 확인** — 응시자 + 결시자 = 재적. 결시는 빈칸이 아니라 명렬에 «결시»+사유
2. **정렬** — 책상 더미 → 트레이(클릭·드래그), 뒷면·위아래(180°) 바로잡기, 번호 오름차순 (초록=맞음 / 노랑=방향 / 빨강=순서)
3. **검사** — 수기·자릿수 마킹·문형·감독관 확인란·답안을 명렬과 비교. 돋보기 렌즈·줌. **교사가 마킹을 대신 고치지 않음**
4. **조치** — 정상 / 학생에게 수정 요청(시험 중) / 교과 확인으로 넘김(시험 후)
5. **결과** — 놓침·오판 해설, 등급 배지, 점수 미터, 난이도별 최고점(localStorage)

### 발견하는 이상 유형

학년·반·번호 마킹 오류, 성명 불일치, 중복 표기, 답안 미표기, 불완전 표기, 과목코드 누락, 감독관 확인란 누락, 수정테이프 이상(**우리 학교 규정 기준**), 문형(홀·짝) 미표기, 컴퓨터용 사인펜 아님, 접힘·얼룩·찢김, 이상 없음.

난이도: 쉬움 10명 / 보통 20명(+10분) / 어려움 30명(+8분).

### 현장 규칙 (하우투·인원 화면에도 표시)

- **인원** 응시 + 결시 = 재적
- **조치** 정상 · 학생 수정 요청 · 교과 확인
- **마킹** 교사가 대신 고치지 않음

## 기술

- Vite + TypeScript, `base: './'` 정적 사이트
- OMR/명렬은 HTML/CSS 자체 제작 (저작권 에셋 없음)
- 수기 서체: Nanum Pen Script (OFL, `public/fonts/`)
- 카드: CSS desk-thumb (Three.js는 의존성에만 있음, 미사용)
- E2E: Playwright (`scripts/e2e.mjs`), 디버그 훅 `window.__TS_E2E__`
- Viewport: `scripts/viewport-check.mjs` (cardsOut/slotsOut === 0)
