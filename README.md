# 교사 시뮬레이터 (Teacher Simulator)

예비교사·교육실습생·학생이 **교사의 자잘한 잡무**를 미니게임으로 연습하는 웹 프로젝트입니다.
학교 정기고사(중간·기말) 답안지 검사 연습을 중심으로, 실제와 비슷한 서류를 책상 위에서 만지며 실수를 줄이는 것이 목표입니다.

> 데모 첫 미니게임: **OMR 카드 검사** (허브의 다른 타일은 잠금)

## 실행

```bash
npm install
npx playwright install chromium   # e2e/스크린샷용 (최초 1회)
npm run dev          # http://localhost:5173
npm run build        # dist/ (GitHub Pages용, base './')
npm run preview      # 빌드 결과 미리보기
npm run e2e          # easy+normal 만점 플로우 · 콘솔 에러 검사 · docs/screenshots/ 갱신 · 클릭/드래그 회귀
npm run test:score   # 시드 고정 채점 스모크 (easy/normal/hard)
npm run test:viewport # 1280×800 · 1024×768 정렬 오버플로 검사 (cardsOut/slotsOut)
npm run screenshots  # 레거시 단계 샷 스크립트
```

시드·난이도·검사시점: `?diff=easy&mode=subject_review&seed=20261104`
(`diff`: easy/normal/hard/multi, `mode`: immediate|subject_review).

정렬 단축키: `F` 뒤집기 · `R` 위아래 · `Enter` 트레이로.

## OMR 카드 검사

1. **검사 시점** — 시험 직후(≤10분, 회수·검사 구역) / 교과 확인(무제한)
2. **응시 인원 확인** — 응시자 + 결시자 = 재적. 결시생은 **빈 답안지**에 결시·사유를 명렬과 대조
3. **정렬** — 단일 반은 번호순, 여러 반은 **반 → 번호(가나다)순**. 뒷면·위아래 바로잡기
4. **검사** — 과목코드·과목명·수기·마킹·도장·손상·화이트를 확인. 문제 부위 클릭으로 이상 선택. **줌만** (돋보기 없음). 교사가 답안을 고치지 않음
5. **조치** — 정상 / 학생 호출하여 기재 사항 확인(학번·이름·과목만) / 채점 반영(오답)·학생 호출 없이 오답 처리 / 교과 확인·판독 보류
6. **결과** — 반별 그룹, 검사 시점 표시, 놓침·오판 해설

### 발견하는 이상 유형

학년·반·번호 마킹 오류, 성명 불일치, 수기 과목명 불일치, 중복 표기, 답안 미표기, 불완전 표기(흐림·한 줄·부분), 과목코드 누락, 감독관 확인란 누락, 수정테이프 이상(**우리 학교 규정 기준**), 컴퓨터용 사인펜 아님, 접힘·얼룩·찢김, 결시 표기·사유 불일치, 이상 없음.
지저분해도 **인식 가능**하면 이상 없음. 판독이 어려우면 교과 확인.

난이도: 쉬움 10명 / 보통 20명 / 어려움 30명 / **여러 반** 2개 반. 시험 직후 제한은 난이도별 5~10분.

### 현장 규칙

- **인원** 응시 + 결시 = 재적 · 결시 빈 답안지
- **조치** 기재 오류(학번·이름·과목명·과목코드)만 학생 호출 · 답안 마킹은 호출 없이 오답 처리 · 교사 수정 없음
- **시험 직후** 인적사항 먼저, 답안은 수정시키지 않음
- **교과 확인** 기재 오류·답안 인식 확인 후 필요 시 학교 성적처리 절차

## 기술

- Vite + TypeScript, `base: './'` 정적 사이트
- OMR/명렬은 HTML/CSS 자체 제작 (저작권 에셋 없음)
- 수기 서체: Nanum Pen Script (OFL, `public/fonts/`)
- 카드: CSS desk-thumb (Three.js는 의존성에만 있음, 미사용)
- E2E: Playwright (`scripts/e2e.mjs`), 디버그 훅 `window.__TS_E2E__`
- Viewport: `scripts/viewport-check.mjs` (cardsOut/slotsOut === 0)
