# 교사 시뮬레이터 (Teacher Simulator)

예비교사·교육실습생·학생이 **교사의 자잘한 잡무**를 미니게임으로 연습하는 웹 프로젝트입니다.
실제와 비슷한 서류·카드(나중엔 간단한 3D 책상)를 만지며 실수를 줄이는 것이 목표입니다.

> 데모 첫 미니게임: **OMR 카드 검사**

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ (GitHub Pages용, base './')
npm run preview      # 빌드 결과 미리보기
npm run screenshots  # Playwright로 단계별 스크린샷
```

시드를 고정하려면 `?seed=12345` 를 붙이세요.

## OMR 카드 검사 (데모)

1. **정렬** — 명렬표 번호 순으로 OMR을 맞추고, 뒤집힌 장을 앞면으로
2. **검사** — 수기·마킹·과목코드·답안을 명렬과 비교해 오류를 고름
3. **결과** — 놓친/잘못 고른 항목과 해설, 점수

오류 유형: 번호 마킹 오류, 학년·반 마킹 오류, 성명 불일치, 이중 마킹, 미마킹, 흐린 마킹, 과목코드 누락, 정상.

## 이슈 트래킹 (로컬 md → 나중에 GitHub Issues)

`docs/issues/` 에 이슈마다 마크다운 파일이 있습니다. 형식은 GitHub Issues로 옮기기 쉽게 맞춰 두었습니다.

## 로드맵 (백로그)

- 출결 정리
- 생기부 검토
- 가정통신문 검수
- 성적 입력 대사
- 실습실 자리 배치

## 기술

- Vite + TypeScript
- 정적 사이트 (서버 불필요) → GitHub Pages 배포 예정
- OMR/명렬은 SVG·HTML/CSS로 자체 제작 (저작권 에셋 없음)
- 카드 뒤집기는 CSS 3D

## 라이선스
